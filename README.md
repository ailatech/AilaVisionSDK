# Aila Vision SDK for iOS


The Aila SDK enables a suite of capabilities on Apple iOS & iPadOS devices, including; data capture, ID-1 card imaging, device health management, and remote status monitoring (RSM). Specific to data capture, the Aila SDK performs image-based barcode scanning using the native camera and processor without the need for additional dedicated peripherals. When paired with Aila's Interactive Kiosk, these capabilities are extended further by way of dedicated aiming and scan field illumination, optics, and an integrated data and power hub. ID-1 imaging (e.g. driver licenses, health insurance cards) is a further option when the kiosk is paired with the ID Tray accessory. The Aila SDK may also be used without Aila dedicated hardware as part of our SoftScan product (requires a licensing plan).
